# CS Equity AI promo materials

Posters, social graphics and a short demo video for [csequityai.org](https://csequityai.org),
in two hand-made styles (see `brand/BRAND.md`): the posters are risograph / screen-print
gig posters, and the video and social graphics are a cut-paper puppet theater.
All copy comes from the website. Every call to action points back to csequityai.org.

`https://csequityai.org/events/vibe-coding-happy-hour.html` (Happy Hour poster).

## Editing

All graphics are generated by `scripts/build.py`. Posters live in `scripts/riso.py`, the video
timeline in `scripts/video.py`, and the paper-cutout toolkit in `scripts/paper.py`.
Shared copy (levels, student projects) is defined once in `build.py`.

```sh
pip install segno fonttools brotli   # QR codes, font metrics for poster type
python3 scripts/build.py        # rewrites every SVG
node scripts/render.mjs         # PNG exports + video/demo.mp4 (needs Playwright + ffmpeg)
```

Fonts (Anton and Space Mono for posters, Fraunces and Special Elite for the rest) are embedded in each SVG, so nothing needs installing.
For print, use the PNGs or export the SVG to PDF from a browser or Inkscape. The paper
texture uses SVG filters, which some design tools (Figma, Illustrator) flatten or drop, so
use the PNG there.
