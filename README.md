# CS Equity AI promo materials

Posters, social graphics and a short demo video for [csequityai.org](https://csequityai.org),
(see `brand/BRAND.md`). The posters are clean, conventional event posters; the video and
social graphics are a cut-paper puppet theater with an original soundtrack.
All copy comes from the website. Every call to action points back to csequityai.org.

## Editing

All graphics are generated by `scripts/build.py`. Posters live in `scripts/posters.py`, the video
timeline in `scripts/video.py`, its soundtrack in `scripts/music.py`, and the paper-cutout
toolkit in `scripts/paper.py`.
Shared copy (levels, student projects) is defined once in `build.py`.

```sh
pip install segno numpy scipy   # QR codes, soundtrack synthesis
python3 scripts/build.py        # rewrites every SVG
node scripts/render.mjs         # PNG exports + video/demo.mp4 (needs Playwright + ffmpeg)
```

Fonts (DM Sans for posters, Fraunces and Special Elite for the rest) are embedded in each SVG, so nothing needs installing.
For print, use the PNGs or export the SVG to PDF from a browser or Inkscape. The paper
texture uses SVG filters, which some design tools (Figma, Illustrator) flatten or drop, so
use the PNG there.

## The video, beat by beat

Each scene stays up long enough to read. `scripts/video.py` counts the characters on screen,
allows 15 characters a second (subtitle guidelines are about 13 for kids and 17 for adults)
plus 1.4 s to spot the text, counts small glanceable labels at half weight, then rounds up to
the music's half-bar so every cut lands on the beat. Run `python3 scripts/video.py` to print
the schedule; change `READ_CPS` or the text and everything, including the music, re-times.

## Music

The soundtrack is original, written in code by `scripts/music.py` (four-on-the-floor drums,
off-beat bass, chord stabs and a chiptune arpeggio over Am–F–C–G at 128 BPM, with a whoosh
and crash on every scene change). Nobody else owns it, so there is nothing to license or credit.

To use a commercial-sounding track instead, swap in any royalty-free file with the same
length, for example from the YouTube Audio Library, Pixabay Music, or Kevin MacLeod's CC BY
catalogue (credit required), such as
[Funkorama](https://opengameart.org/content/funkorama):

```sh
ffmpeg -i video/demo.mp4 -i your-track.mp3 -map 0:v -map 1:a -c:v copy -shortest video/demo-alt.mp4
```
