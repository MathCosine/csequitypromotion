# CS Equity AI promo materials

Posters, social graphics and a short demo video for [csequityai.org](https://csequityai.org).
All copy comes from the website. Every call to action points back to csequityai.org.

| File | What it is | Size |
|---|---|---|
| `posters/poster-build-with-ai.svg` | Main poster: what we do + the three-level path | 18×24 in (1800×2400) |
| `posters/poster-vibe-coding-happy-hour.svg` | Vibe Coding Happy Hour, aimed at schools hosting a session | 18×24 in |
| `posters/poster-built-by-students.svg` | Six student projects from the AI Tutor for [X] course | 18×24 in |
| `social/square-0*.svg` | Instagram / Facebook posts | 1080×1080 |
| `social/facebook-cover.svg` | Facebook page cover | 1640×624 |
| `video/demo.svg` | 30-second animated demo (loops in any browser) | 1920×1080 |
| `video/demo.mp4` | Same demo rendered as video, for Instagram / YouTube / slides | 1920×1080, 30 fps |
| `brand/` | Logo mark, horizontal logo, palette and voice notes | |

`posters/png/` and `social/png/` have PNG exports ready to upload.

QR codes on the posters go to `https://csequityai.org` (main and student posters) and
`https://csequityai.org/events/vibe-coding-happy-hour.html` (Happy Hour poster).

## Editing

All graphics are generated by `scripts/build.py`, so a copy change only has to be made once.

```sh
pip install segno               # QR codes
python3 scripts/build.py        # rewrites every SVG
node scripts/render.mjs         # PNG exports + video/demo.mp4 (needs Playwright + ffmpeg)
```

For print, open the SVG in Illustrator/Inkscape/Figma and export to PDF. Fonts are Inter;
install it first or the text falls back to Segoe UI / Helvetica.
