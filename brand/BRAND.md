# CS Equity AI — brand starter kit

A starter identity for promo materials. Swap freely if the site's styling differs.

## Mark
`logo-mark.svg` — code brackets `< >` (computer science) around an equals sign (equity),
with two gold "nodes" (AI / connection). `logo-horizontal.svg` adds the wordmark.

## Palette

| Token     | Hex       | Use                                   |
|-----------|-----------|---------------------------------------|
| Indigo    | `#1E1B4B` | Primary background / headline text    |
| Coral     | `#FF6B5B` | Primary accent, "AI", calls to action |
| Teal      | `#14B8A6` | Secondary accent, URLs, highlights    |
| Sun       | `#FBBF24` | Sparks, nodes, small highlights       |
| Cream     | `#FFF8EE` | Light background / text on indigo     |
| Lavender  | `#A5B4FC` | Muted text on indigo                  |

## Type
Inter (800 for headlines, 600 for labels, 400 for body). All SVGs fall back to
Segoe UI / Helvetica / Arial if Inter isn't installed.

## Voice
Write like a person, not a brochure. The site's own lines are the model:
- "We teach students to build with AI, not just use it. Free."
- "No tuition, no gatekeeping. Just a browser and curiosity."
- "Each level ends with something real."
- "Free, like everything we run."

Rules of thumb:
- Only claim what's on csequityai.org. No invented stats or student counts.
- Short sentences. Concrete nouns (a certificate, a working AI system, a pitch).
- Skip words like "empower", "unlock", "revolutionize", "journey", "cutting-edge".
